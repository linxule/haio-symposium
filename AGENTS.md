# HAIO Symposium maintenance

Keep this a small static archive. Use the supplied 2024 event content as historical information; do not replace affiliations with current ones or use earlier flyers. The Google Form is intentionally omitted.

Edit content/event.json for people and programme details, index.html for structure, and public/styles.css for layout. Run npm run build and npm run check. Verify desktop and mobile layout after visual changes.

Do not commit font binaries, raw recovery archives/PDFs, credentials or generated dist/. Keep third-party image provenance in content/assets.json. Preserve the original HAIO colours and supplied artwork. Deployment and custom-domain/DNS changes require the owner's authorization.
